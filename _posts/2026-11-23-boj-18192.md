[문제 링크](https://acmicpc.net/problem/18192)

## Summary

$1 \leq N \leq 200$이고 두 명령어의 사용이 가능하다

- vector\<int> copy_array(): 현재 배열을 복사한다. 2500회 이하 사용 가능
- shuffle_array(s, e): [s, e]의 배열을 랜덤으로 섞는다. 2500회 이하 사용 가능

두 명령어를 잘 사용해서 배열을 정렬하는 게 이 문제의 목표.

## Solution

사실 26001과 비슷한 문제인데 이것도 무작위화에 의해 이득을 볼 수 있다.

## Code

```cpp
#include "bogoSort.h"

void sort_array(int N){
    for (int i = 0; i < N - 1; i++){
        while (true){
            std::vector<int> A = copy_array();
            int anc = -1;
            for (int j = i; j < N; j++){
                if (A[j] == i){anc = j; break;}
            }
            if (i == anc) break;
            shuffle_array(i, anc);
        }
    }
    return;
}
```
