BOJ 26001 풀이

Created on November 20, 2026

2026   ·   PS   math   ·   Problem   Solving

문제 링크

6개월만에 BOJ가 돌아온 이후로의 첫 문제입니다.

Summary

인터랙티브 문제이고 입력으로는 맵의 x축 size인 $w$, 높이(y축 size) $h$가 주어진다. 맵의 x축 기준 위치 $x$에는 높이가 $h$ 이하인 빌딩이 존재하고 다음과 같은 질의를 최대 12000번 할 수 있다.

  • ? $w_i$ $h_i$: $w_i$번째의 $h_i$ 부분은 빌딩이면 ‘building’, 아니면 ‘sky’를 출력한다.
  • ! $w_i$ $h_i$: $w_i$이 가장 높은 빌딩임을 출력한다.

인터랙티브는 비적응적임에 유의하라

Solution

일단 전 구간을 탐색하려면 10000회는 기본적으로 사용해야 하고, 이분 탐색으로 쓸 수 있는 건 약 2000회이다.

간단한 방법

가장 간단한 방법은 x축을 다 순회하면서 이분탐색을 갈기는 방법이다. 하지만 그 방법은 $O(w \log h)$이고 당연히 12000회를 뛰어넘는다.

최댓값 저장

좀 더 생각한다면 이때까지의 최댓값을 저장하는 방법이 있다. $i = 1$부터 $i = w$까지 쭈욱 훑을 때, $i = k$까지의 최댓값을 $H$로 저장한다는 것이다. 그리고 (?, $k + 1$, $H + 1$)라는 질의를 해볼 수 있다.

  1. sky일때: 그렇다면 $k + 1$ 건물은 최대 $H$이다. 높이가 최대인 아무것이나 출력해도 돼기 때문에 더 탐색할 이유가 없으므로 1회를 소모하고 넘길 수 있다.
  2. building일때: $k + 1$ 건물은 최소한 $H + 1$ 이상이므로 이분탐색을 통해 정확한 빌딩의 높이를 찾고 최대 높이와 인덱스를 갱신한다.

그렇다고 해도 아직 부족하다. 만약 $i = 1$부터 $i = w$까지 증가하는 수열이라면? 똑같이 $O(w \log h)$이다! 2000회에는 턱없이 부족하다.

배열 섞기

놀랍게도 배열을 랜덤으로 섞은 후 돌리면 매우 높은 확률로 2000회 내에 끝낼 수 있다. 같은 높이는 그냥 넘기기 때문에 모든 빌딩의 높이가 모두 다를 때를 일반성으로 삼고 한 가지 사실과 점프를 정의해보자.

  • 이분 탐색 시 64회 이하의 추가 질의가 필요하다.
  • 이분 탐색이 필요할 때, 즉 새로운 최댓값을 찾았을 때를 ‘점프’라고 하자.

그렇다면 ‘점프’는 $\frac{2000}{64} \approx 33$회 이하로 일어나야 하며, 알고리즘이 정당화되려면 랜덤으로 섞어서 점프가 33회 이상일 확률이 매우 낮음을 증명하면 된다.

현재 $i$번째 값을 볼 때 가장 클 확률, 즉 점프가 발생할 확률은 $\frac{1}{i}$이다. 그렇다면 점프 횟수의 기댓값 $dp[w]$는 조화수와 동일하다.

$ dp[w] = H_{w} \approx \log w $

분산도 계산하면 다음과 같다. $i$번째 막대가 $1$에서 $i$ 사이 가장 클 확률이 $\frac{1}{i}$이므로 베르누이 분포 써서 계산하면

$ \text{Var} = \sum \limits_{i = 1}^{10000} \frac{1}{i} \left( 1 - \frac{1}{i} \right) = H_{10000} - \frac{\pi^2}{6} = 8.xx $

기댓값이 10 이하이고 표준편차가 2점대 후반인데, 체르노프 한계를 쓰면 확률 상한을 구할 수 있겠지만 안봐도 매우 낮음은 확실해보인다. 그래서 33회 안에 풀이가 가능하다.

Code

import sys, random

input = sys.stdin.readline

def f():
    w, h = map(int, input().split())
    rd = list(range(w))
    random.shuffle(rd)
    mh, mi = 0, 1
    for i in rd:
        print(f"? {i + 1} {mh + 1}", flush=True)
        if input().rstrip("\n") == "sky":
            continue

        mi = i + 1
        l, r = mh + 2, h + 1
        while l < r:
            m = (l + r) // 2
            print(f"? {mi} {m}", flush=True)
            if input().rstrip("\n") == "sky":
                r = m
            else:
                l = m + 1
        mh = l - 1

        if mh == h:
            break

    print(f"! {mi} {mh}", flush=True)
