BOJ 16656 풀이

Created on November 21, 2026

2026   ·   PS   math   ·   Problem   Solving

문제 링크

Summary

인터랙티브 문제이고 길이 $10$ 이하의 배열 집합 $a_1, a_2, \cdots, a_n$이 주어진다. 각 배열 내 원소는 모두 다르며 두 개의 질문이 가능하다.

  • ? $m$ $q_1$ $q_2$ $\cdots$ $q_m$: $a_{q_1}, a_{q_2}, \cdots, a_{q_m}$을 구분자 없이 순서대로 출력한다.
  • ! $k_1\, a_{1, 1},\, a_{1, 2},\, \cdots,\, a_{1, l_1},\, \cdots,\, k_n,\, a_{n, 1},\, \cdots,\, a_{n, l_n}$: 각 배열의 크기와 배열의 구성을 차례대로 출력한다.

최대 20번 질의가 가능하다.

Solution

아래 질문을 하면 한 번에 배열 내 모든 원소를 알아낼 수 있다.

  • $?\, 1\, 1\, 2\, 2 \cdots n \, n$

왜냐면 배열 내 원소는 모두 다르기에 입력을 순차적으로 받다가 중복되는 원소가 나오면 바로 끊을 수 있기 때문. 참고로 $1 \leq m \leq n$이란 조건이 존재하므로 2번 질문해야 하니 주의하자.

Code

def f():
    n = int(input())

    if n == 1:
        print("? 1 1", flush=True)
        S = list(map(int, input().split()))
        print("! " + " ".join(map(str, S)), flush=True)
        return

    ans = []
    step = n // 2

    for start in range(1, n + 1, step):
        end = min(n, start + step - 1)
        q = []
        for i in range(start, end + 1):
            q.extend([i, i])

        print(f"? {len(q)} " + " ".join(map(str, q)), flush=True)
        S = list(map(int, input().split()))

        l = []
        timer = 0
        for i in range(1, S[0] + 1):
            if timer:
                timer -= 1
            elif S[i] in l:
                timer = len(l) - 1
                ans.append(l[:])
                l.clear()
            else:
                l.append(S[i])

    rt = ["!"]
    for i in ans:
        rt.append(str(len(i)))
        rt.extend(map(str, i))
    print(" ".join(rt), flush=True)
